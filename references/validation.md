# 验证要求

每个案例保存以下四组实际执行结果：

1. 自对照：原作与原作比较，应为 100。
2. 等价改写：变量改名、表达式等价改写、简单组件拆分，分数应保持稳定。
3. 定向修改：删除对象、写入未使用的同名文字、动画绑到其他对象、冻结透明度、删掉缩放、改变起止时间。相应检查应下降，其余检查保持合理稳定。加入不支持语法时应给出未知状态。
4. 真实复刻：使用已有复刻源码，逐项核对两边代码证据。确认脚本指出的差异确实存在。

测试报告写输入指纹、命令、期待结果、实际结果和通过范围。人工核对用于校准和审核测量器；最终评分由脚本计算。

`verified` 只用于已验证的检查范围。剩余对象、CSS、复杂 SVG 或动态行为列入限制。封存工具校验包结构与文件指纹；测试结果需保留可复查证据。
